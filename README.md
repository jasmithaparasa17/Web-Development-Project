![Image3](https://github.com/user-attachments/assets/e21c9d0e-662a-4a52-a80d-d62ac178f8e0)# 🍫 Chocolate Cake Recipe Webpage

This project is a simple and elegant HTML and CSS-based webpage that displays a chocolate cake recipe. It includes step-by-step instructions, a list of ingredients, and images to illustrate each step in the baking process.

## 📌 Features

- Responsive HTML layout
- Stylish CSS for recipe card display
- Toggle button to show/hide ingredients
- Step-by-step instructions with embedded images
- Simple JavaScript to handle UI interaction

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Chocolate-Cake-Recipe.git
   ```

2. Open the `Chocolate Cake Recipe.html` file in any web browser.

3. Enjoy the visual recipe experience!
